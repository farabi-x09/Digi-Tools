 Project Name:   
  Digi Tools


***
Description:  
Premium digital tools for creators, professionals, and businesses. Work smarter with our suite of powerful tools. We can buy these tools from this website which will make our work easier.


*****
Technology :  
 React.js    
Tailwind CSS,   
 DaisyUI  
JavaScript (ES6+)  
React-Toastify (NPM Package)  
JSON (for product data)   
React Icons  
Lucide Icons  

********
3 Features about project:  
1. We can see the prices of all the products we purchased at once.
2. We can exclude products from the selected products if we want.
3. The same product will not be accidentally selected multiple times.
