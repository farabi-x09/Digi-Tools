## 🧐 Project Overview
This application is a modern e-commerce storefront designed for digital resources. It allows users to browse products categorized by tags (Popular, Best Seller, New), view detailed features, and manage a shopping cart. The project focuses on state management in React, seamless UI toggling, and an interactive user experience using React-Toastify for notifications.

---

## ✨ Key Features

* **Dynamic Product Management:** Products are loaded from a structured JSON dataset, featuring automated categorization with specialized tags like "Popular" or "Best Seller."
* **Real-time Cart System:** An interactive cart that updates the Navbar count instantly. Users can add items, remove specific products, and "Proceed to Checkout" to clear the cart with a single click.
* **Intuitive UI Toggling:** A centralized navigation system that allows users to switch seamlessly between the Product Gallery and the Cart view without page reloads.

## ⚙️ Installation & Local Setup
To run this project on your local machine, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone https://github.com/farabi-x09/Digi-Tools.git
    ```
2.  **Navigate to the project folder:**
    ```bash
    cd Digi-Tools
    ```
3.  **Open the project:**
    * Simply open `index.html` in your browser.
    * *Recommended:* Use the **VS Code Live Server** extension for the best experience.
